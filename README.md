校园课程管理系统

一、项目简介

本项目是一个基于 Spring Boot 开发的校园课程管理系统，主要用于管理学生信息、课程信息以及学生选课业务。

项目采用 Controller、Service、Mapper 分层架构，通过 MyBatis-Plus 实现数据库操作，使用 MySQL 存储业务数据。

在选课业务中，系统实现了重复选课校验、课程容量限制、事务管理和基于 "SELECT ... FOR UPDATE" 的并发控制，降低并发选课导致超额选课的风险。

二、技术栈

- 开发语言： Java
- 后端框架： Spring Boot
- 数据库： MySQL
- 持久层框架： MyBatis-Plus
- 数据库访问： SQL
- 接口测试： Postman,JMeter
- 开发工具： IntelliJ IDEA、MySQL Workbench

三、核心功能

1. 学生管理

支持学生信息的基本增删改查。

支持根据业务需求查询学生信息。

2. 课程管理

支持课程信息的增删改查。

支持课程分页查询。

支持维护课程容量等信息。

3. 学生选课管理

支持学生选择课程。

校验学生是否存在、课程是否存在。

防止学生重复选择同一门课程。

根据课程容量限制选课人数。

支持学生取消已选择的课程。

支持查询指定课程的选课学生名单。

支持对课程学生名单进行分页查询。

四、项目亮点

1. 业务校验与异常处理

在 Service 层实现选课业务校验，针对学生不存在、课程不存在、重复选课和课程满员等情况抛出业务异常，提高业务逻辑的可维护性。

2. 事务管理

在选课和取消选课等业务操作中使用 Spring 事务管理，保证相关数据库操作按照预期提交或回滚。

3. 并发选课控制

使用 SELECT ... FOR UPDATE 对课程记录加锁，协调同一门课程的并发选课请求，降低多个请求同时通过容量检查导致超额选课的风险。

4. 多表关联查询

通过学生表、课程表和选课关联表实现多表关联查询，支持查询指定课程的学生名单。

5. 分页查询

使用 MyBatis-Plus 的分页功能实现课程查询和课程学生名单分页查询，提高大量数据场景下的查询效率。

五、数据库设计

本项目主要涉及三张核心数据表。

1. 学生表（student）

用于存储学生的基本信息。

主要字段：

- "id"：学生 ID，主键。
- 其他字段：根据项目实际设计存储学生信息。

2. 课程表（course）

用于存储课程信息。

主要字段：

- "id"：课程 ID，主键。
- "capacity"：课程容量，用于限制选课人数。
- 其他字段：根据项目实际设计存储课程信息。

3. 学生选课关联表（student_course）

用于记录学生与课程之间的选课关系。

主要字段：

- "id"：选课记录 ID，主键。
- "student_id"：学生 ID。
- "course_id"：课程 ID。

4. 表之间的关系

- 一个学生可以选择多门课程。
- 一门课程可以被多个学生选择。
- 学生与课程之间属于多对多关系。
- 使用 "student_course" 关联表维护学生和课程之间的选课关系。
